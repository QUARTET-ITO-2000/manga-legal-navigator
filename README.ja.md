# 漫画正版ナビ（Manga Legal Navigator）

**漫画のページを開く → その作品の正規版が DLsite / FANZA / Melonbooks にあるか、どこで買えるかがすぐ分かる。**

`manga-legal-navigator` は Manifest V3 の Chrome / Chromium 拡張機能です。開いているページを読み取り、作品名（日本語の原題を優先）を判定し、正規ストアを順番に検索して、各候補をスコアリングしたうえで、ページ右下に小さなカード（商品名・価格・直リンク）を表示します。

確度が足りないときは**「該当する商品は見つかりませんでした」**とはっきり表示し、手動検索のリンクを出します。**それらしい別の商品を勧めることはありません。**

**言語:** [English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

> ### 対象と免責
>
> * 本ツールは **成人（R18）向けコンテンツ**を扱うもので、**成人のみ**を対象としています。
> * **公開ページを読み取り、正規ストアへリンクするだけ**です。代理ログイン、カートへの追加、購入、ダウンロード、課金壁・DRM・CAPTCHA・年齢確認の回避は行いません。
> * ページの適法性を判断するものではなく、どこかへ情報を送信することもありません。処理はすべてお使いの端末内で完結します。
> * ストア名・商標は各権利者に帰属します。本プロジェクトは DLsite・FANZA（DMM）・Melonbooks とは無関係です。

## できること

* **現在のページを読み取る** — `<title>`、`h1`–`h4`、`og:title`、JSON-LD、ギャラリーの情報ブロック（`Tags / Groups / Languages / Pages`）、本文サンプル。
* **作品名を抽出・整形する** — サイト名、広告文、話数、`[DL版]` / `[Chinese]` などのタグを除去し、ローマ字表記や翻訳タイトルより**日本語の原題を優先**します（各ストアは日本語の商品名でインデックスされています）。
* **正規ストアを順番に検索** — DLsite → FANZA → Melonbooks。どこか1つで高確度の一致が出たらそこで打ち切ります。
* **スコアリングと段階表示** — `≥85` は「見つかりました」、`62–84` は「候補あり」（最大3件）、`<62` は**一切表示しません**。
* **ページ上のカード**（Shadow DOM、折りたたみ / 閉じる可、レイアウトに影響しません）と、詳細・設定・キャッシュ管理ができる**ツールバーのポップアップ**。
* **クライアントサイド遷移に対応** — リロードせずに内容が入れ替わるサイト（一部のギャラリーサイトが該当します）では、「遷移ゲート」が新ページの描画完了を待ってから読み取ります（v0.3.0 で修正した問題。→[変更履歴](#変更履歴)）。
* **デフォルトでは静か** — 作品ページらしくないページではカードを出さず、リクエストも送りません。

### 表示イメージ

ページ右下のカード:

```
┌────────────────────────────────┐
│ 📚 見つかりました        –  ×  │
│                                │
│ 《サンプル作品タイトル》        │
│ [DLsite] 1,980円 約87元         │
│ サークル / 作者                │
│                                │
│ [ 商品を見る ]  [ 折りたたむ ]  │
│ 購入するかどうかはご自身で。    │
└────────────────────────────────┘
```

ポップアップではさらに、判定した作品名とその出典、ストアごとの結論（見つかった / 見つからない / 年齢確認が必要 / 取得失敗）、一致度、「ページに表示」「再解析」ボタンが確認できます。

## 対応するページの種類

| ページの種類 | 例 | 判定方法 |
| --- | --- | --- |
| オンライン漫画の閲覧ページ | `【作品名】第12話 - 免费漫画` | タイトル内の話数マーカー + 漫画キーワード + 本文サンプル |
| 同人誌ギャラリー | `Tags / Groups / Languages / Pages` などの情報項目がある作品ページ | 情報ブロックの構造（2項目以上）+ ホストのヒント + 画像数 |
| 汎用的な作品詳細ページ | `/comic/…`、`/gallery/…`、`/read/…` を含む URL + 多数の画像 + 漫画キーワード | URL の形 + 画像数 + キーワードの組み合わせ |

それ以外（ブログ、ニュース、検索エンジン、動画・ショッピングサイトなど）は対象外です。カードも出さず、リクエストも送りません。

## 仕組み

```
content script（ページ側）                 service worker（バックグラウンド）
──────────────────────────────────────    ─────────────────────────────────────────
title / 見出し / og / JSON-LD を読む  ──▶ 「作品ページらしいか」を判定
ギャラリーの情報ブロックを読む             タイトルを整形 → 検索バリアントを生成
クライアントサイド遷移を監視               DLsite → FANZA → Melonbooks
                                          結果を解析し、照合して段階付け
Shadow DOM カードを描画             ◀──  状態オブジェクトを生成（一致 / 候補 / なし）
```

1. **content script** がページ情報を収集し、バックグラウンドへ送ります（`src/content/extractor.js`）。
2. **ページ判定** が分析対象かどうかを決めます（`src/lib/site-filter.js`）。
3. **クリーナー** が生のタイトルから検索用の作品名と複数のバリアントを作ります（`src/lib/cleaner.js`）。
4. **ストアアダプタ** が検索 URL を組み立て、取得し、結果を解析します（`src/stores/`）。クロスオリジン通信はバックグラウンドのみが行えます。
5. **マッチャー** が4種類の文字列類似度で採点し、段階を決めます（`src/matching/matcher.js`）。
6. 生成された状態がカードとして描画され、タブごとにキャッシュされます。ポップアップも同じ状態を読みます。

chrome API の境界より上はすべて純粋関数なので、パイプライン全体を Node 上で `src/stores/fixtures/` のスナップショットに対してテストできます。

## 対応ストア

| ストア | 検索エントリ | 結果の構造 | 備考 |
| --- | --- | --- | --- |
| **DLsite** | `https://www.dlsite.com/<section>/fsr/=/language/jp/keyword/<キーワード>/` | `li[data-list_item_product_id]` + `dd.work_name` / `dd.work_price_wrap` | キーワード内の空白は**必ず** `+`。`%20` は WAF により HTTP 403 |
| **FANZA**（DMM） | `https://www.dmm.co.jp/search/=/searchstr/<キーワード>/` | `/-/detail/=/cid=d_XXXXXX/` + `p.text-sm.font-bold` + `770円` + `サークル：…` | 年齢確認 Cookie が必要（下記） |
| **Melonbooks** | `https://www.melonbooks.co.jp/search/search.php?name=<キーワード>&adult_check_flg=1` | `li.product_NNNNNNN` + `p.item-ttl.product_title` + `p.item-price` | Cookie 不要 |
| **Pixiv** | `https://www.pixiv.net/ajax/search/artworks/<キーワード>?…&s_mode=s_tag`（JSON） | `body.illustManga.data[]` → `id` / `title` / `userName` / `xRestrict` | ブラウザの Pixiv セッションを再利用。**R-18 作品はログイン＋年齢確認をしないと検索に出ません** |
| **Fantia** | `https://fantia.jp/api/v1/search/posts?q=<キーワード>`（JSON） | `posts[]` → `id` / `title` / `fanclub.name` | 公開 JSON API。成人向けは年齢確認が必要な場合があるためブラウザのセッションを再利用します |

### FANZA と年齢確認

FANZA へのリクエストは `credentials: 'include'` で送信されるため、**ブラウザに既にある年齢確認の状態（`age_check_done=1`）を再利用**します。年齢確認ページが返ってきた場合、拡張機能は**「結果なし」と偽ることはせず**、そのストアを「年齢確認が必要」と表示して確認用リンクを出します。確認後に「再解析」を押してください。

Cookie を伴うのは FANZA のみで、DLsite と Melonbooks は常に資格情報なしで取得します。

## インストール

### 動作環境

* Chrome / Chromium **102 以降**（Manifest V3 + ES モジュールの service worker）。Edge でも動作します。

### 配布アーカイブから

1. `manga-dlsite-navigator-v0.3.0.zip` をダウンロードして解凍します。
2. `chrome://extensions/` を開き、右上の**デベロッパー モード**を有効にします。
3. **パッケージ化されていない拡張機能を読み込む** をクリックし、`manifest.json` があるフォルダを選びます。

### ソースから

```bash
git clone https://github.com/<your-account>/manga-legal-navigator.git
```

あとは同じく「パッケージ化されていない拡張機能を読み込む」でリポジトリのフォルダを指定するだけです。**ビルドもバンドラーも依存関係もありません。**

任意: 拡張機能の詳細ページで「**ファイルの URL へのアクセスを許可する**」を有効にすると、`tests/pages/` のローカルテストページを試せます（通常のサイト閲覧には不要です）。

## 使い方

1. 漫画 / 同人誌のページを開きます。作品を認識できれば、1〜2秒で右下にカードが出ます。
2. **商品を見る**（またはポップアップの同名ボタン）をクリックすると、商品ページが新しいタブで開きます。購入するかどうかはご自身で判断してください。
3. ツールバーのアイコンをクリックすると詳細が表示されます: ページタイトル、判定した作品、ストアごとの結論、一致度、設定。
4. 結果がおかしいときは**再解析**を押してください。ページを移動した直後にポップアップを開いた場合も、新しいページで自動的に確認し直します。

### ポップアップの設定

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| 拡張機能を有効にする | オン | マスタースイッチ。オフにすると読み取りも通信もカードも行いません。 |
| 作品を認識したらページにカードを表示 | オン | オフにすると結果はポップアップ内のみ、または「ページに表示」を押したときだけ表示されます。 |
| 作者 / サークル名でも検索する | オン | ページの作者・サークル名でもう一度検索します。サイトによっては（特に Pixiv）別タイトルで登録されているため、タイトル検索だけでは見つかりません。 |
| オフラインのサンプルデータを使う（デバッグ） | オフ | `src/stores/fixtures/` のサンプルスナップショットでパイプライン全体を実行します（通信なし）。 |
| 「漫画ページかどうか」の判定をスキップ（デバッグ） | オフ | すべてのページを分析します。新しいストアアダプタの開発時に便利です。 |

ポップアップには保存済みの検索キャッシュ件数と、**検索キャッシュを消す**ボタンもあります。

## 検証

2026-09-11 に Chrome 上で、実際の同人誌ギャラリーページとストア3社に対して手作業で確認しました:

| 確認した項目 | 結果 |
| --- | --- |
| ギャラリーページのタイトル抽出（日本語の原題が副次的な見出しにあり、ローマ字/英語のタイトルが併記されているケース） | 日本語の原題で検索される |
| DLsite に商品がある作品（値引き中の商品を含む） | 商品名・現価格・定価・セール表示を正しく取得 |
| DLsite には無く **FANZA にはある**作品 | FANZA の結果を表示し、DLsite は「見つかりません」と正しく表示 |
| Melonbooks に商品がある作品 | Melonbooks の結果と価格を表示 |
| 3社のいずれにも無い作品 | 正しく「見つかりません」と表示（誤った商品を勧めない） |
| クライアントサイド遷移: 作品を開いて **100 ミリ秒以内**にポップアップを開く | 新しい作品が表示され、前のページのタイトルは表示されない |

> **ドキュメントの方針:** 本リポジトリには**実在作品のタイトル・商品 ID・ストアのリンクは一切含まれていません**（ドキュメント・テスト・スナップショットのいずれも `サンプル作品アルファ` や `RJ00000000` などのプレースホルダです）。ストアの一覧は第三者のコンテンツであり、実行時にご自身の端末上で読み取られるだけです。再検証したい場合は、気になる作品ページを開いて、カードの内容とストアの検索結果を見比べてください。

## プライバシーと権限

* アカウント登録なし、テレメトリなし、解析なし、自前のサーバーもありません。
* 読み取るのは**公開ページの情報**（タイトル、見出し、`og:`/JSON-LD、ギャラリーの情報ブロック、本文サンプル）だけで、検索リクエストの送信先は**上記3ストアのみ**です。
* キャッシュは端末内の `chrome.storage.local` に保存されます。キャッシュキーは検索キーワードのハッシュで、**閲覧履歴は保存しません**。ポップアップからいつでも消せます。

| 権限 | 用途 |
| --- | --- |
| `storage` | 設定と検索結果キャッシュの保存 |
| `activeTab` | ポップアップが現在のタブを読み、状態表示と手動の再解析を行うため |
| `host_permissions`: `dlsite.com`、`dmm.co.jp`、`melonbooks.co.jp` | 各ストアの公開検索ページの取得。content script は CORS の制約を受けるため、バックグラウンドから取得します |
| `http/https/file` にマッチする content script | 表示中のページを読み取るため。インストール時に Chrome が「すべてのウェブサイト上のデータの読み取りと変更」と表示しますが、ページタイトルを読む拡張機能には必ず付く警告です |

**意図的に実装していないこと**: 各ストアへのログイン、パスワードの取り扱い、フォーム送信、自動購入・自動ダウンロード、アクセス制限 / DRM / CAPTCHA / 年齢確認の回避。

## 設定値（チューニング）

しきい値とタイミングはすべて [`src/lib/config.js`](src/lib/config.js) にあります:

| キー | 既定 | 意味 |
| --- | --- | --- |
| `matcher.high` | 85 | このスコア以上で「見つかりました」 |
| `matcher.possible` | 62 | このスコア以上で「候補あり」として表示 |
| `matcher.minCandidate` | 50 | これ未満の候補は表示しない |
| `matcher.tieMargin` | 6 | 2位との差がこれ未満なら、1件に絞らず候補を並べる |
| `cache.positiveTtlMs` | 30分 | 一致結果のキャッシュ寿命 |
| `cache.negativeTtlMs` | 5分 | 「見つからない」のキャッシュ寿命（短めにして新作を拾いやすく） |
| `search.minIntervalMs` | 900ms | ストアへのリクエスト最小間隔（相手に負荷をかけない） |
| `search.timeoutMs` | 12秒 | 1リクエストのタイムアウト |
| `extractor.urlPollMs` | 900ms | content script が URL 変化を確認する間隔 |
| `extractor.settleQuietMs` / `settleMaxWaitMs` | 400ms / 5秒 | 遷移ゲート: DOM が静かであるべき時間と、最大待機時間 |


### テスト

```bash
node --test tests/*.test.js      # 141 件、すべてオフライン
npm test                         # 同上
node tools/lint-anonymity.mjs    # 実在の商品 ID / ギャラリー ID が混入していないか検査
```

範囲: タイトル整形（過剰に削らないことを確認する反例つき）、マッチングのしきい値、ページ判定、ストアのパーサ（HTML スナップショット）、パイプライン全体、カードのテンプレート、ポップアップ、そしてクライアントサイド遷移ゲート（`tests/content-nav.test.js`）。

### 実サイト探針

```bash
node tools/probe-dlsite.mjs "サンプル作品名"
node tools/probe-dlsite.mjs --title "【サンプル作品】第3話 - 免费漫画 - 示例漫画网"
node tools/probe-dlsite.mjs "キーワード" --raw      # 生 HTML を出力してセレクタを再調整
```

検索 URL、HTTP ステータス、解析できた件数、上位候補とスコアを出力します。ストアのリニューアル時、URL が壊れたのかセレクタが壊れたのかを即座に切り分けられます。

### ローカルテストページ（要件のテスト A–F）

`tests/pages/` に `file://` で開ける6枚のページがあり、それぞれ冒頭に期待結果が書かれています:

| テスト | ファイル | 期待 |
| --- | --- | --- |
| A | `test-a.html` | タイトル + 話数 → 話数が除かれ、残った作品名で検索される |
| B | `test-b.html` | 【】・話数・サイト名つき → 3つとも整形で除去される |
| C | `test-c.html` | 存在しない作品 → 「見つかりません」+ 検索リンク（**商品は表示しない**） |
| D | `test-d.html` | A/B と同じ整形経路。候補リストの再現方法をページ内に記載 |
| E | `test-e.html` | 成人向け作品 → 全年齢作品とまったく同じ流れ |
| F | `test-f.html` | プログラミングのブログ → **カードを出さない**、何も推薦しない |

これらのページは**サンプルの作品名**を使っています（実在の作品名ではなく、実在作品をもじったものでもありません）。そのためストア検索では何も見つからず、カードが「見つかりません」と表示されるのが期待どおりの結果です。実際のヒットを確認したい場合は、いずれかのページの `<title>` / `og:title` / `h1` を気になる作品名に差し替えて再読み込みしてください。

### テスト用スナップショット

`src/stores/fixtures/*.html` は**手書きの「サンプルスナップショット」**です。DOM 構造・クラス名・属性は実ページと同じ（パーサはこれに合わせて書かれています）ですが、商品名・商品 ID・サークル名・画像 URL はすべてプレースホルダです。ストアのパーサをオフラインで回帰テストするために存在します。

**実ページ**でパーサを確認したい場合は、取得した HTML を `src/stores/fixtures/local/` に置いてください（gitignore 済みなので、実在の商品データがリポジトリに入ることはありません）。

## 既知の制限

1. **翻訳タイトルは一致しません。** 各ストアの索引は日本語の商品名が中心です。中国語や英語の訳題しか分からない場合は「見つかりません」＋手動検索リンクになります。
2. **そもそも扱っていない作品があります。** 商業出版社の作品（集英社・講談社など）は DLsite / FANZA / Melonbooks に無いことが多く、その場合の「見つかりません」は正しい結果です。
3. **短すぎるタイトル**（3文字未満）は DLsite で常に 0 件になるため、手動検索リンクにフォールバックします。
4. **マッチングは意図的に保守的です。** 62 点未満は表示しないため、他商品名の一部でしかないクエリは「見つかりません」となり、それらしい別商品を勧めることはありません。
5. **特殊なタイトル形式**（サイト名と作品名が区切り文字なしで連結しているなど）は整形しきれないことがあります。その場合も結果は「見つかりません」で、推測はしません。
6. **ストアのリニューアル。** パースは実測した HTML に基づき、スナップショットテストで保護されています。マークアップが変わった場合は「検索に失敗しました」と表示し、黙って「結果なし」にはしません。`tools/probe-dlsite.mjs` で再調整してください。
7. **ネットワーク環境。** 一部の回線からは各ストアに到達できず、その場合は検索失敗と表示されます。リクエストは最小 900ms 間隔・30分キャッシュで抑えています。
8. **クライアントサイド遷移**は `pushState` フックと 0.9 秒間隔の URL ポーリングで検出し、その後 DOM が落ち着くのを待ちます（400ms の静穏、最大 5 秒）。極端に遅いサイトでは最初の解析が前の内容になることがありますが、新しい内容が来たら自動で再解析し、ポップアップの「再解析」でもやり直せます。
9. **角括弧つきのサークル名** — `[サークル名 (作者)] 作品タイトル` のような形では、最初の検索バリアントが括弧つきのままになります（2つ目のバリアントでは括弧を外します）。
10. **ブラウザ:** Chrome / Chromium を優先。Edge は動作する見込みです。Firefox は `browser.*` のシムと manifest の調整が必要です。
11. **雑誌に収録された章:** 同人作品が雑誌に掲載された場合、ストアは**その号**（`…号 …`）しか扱っておらず、ギャラリーには章のタイトルが載っています。両者に共通する文字列がないため「見つかりません」と表示されます。検索リンクはその号に到達しますが、自動で一致と判定すると検証できない商品を推薦することになります。
12. **Pixiv の R-18 にはセッションが必要:** Pixiv は「ログイン済み＋年齢確認済み」のセッションにしか成人向け作品を返しません（実測: 匿名で人気の成人向けタグを検索すると、総数は同じでも返るのは全年齢のみ）。そのため Pixiv へのリクエストは Cookie 付きで送り、検索が空だった場合はその旨をポップアップに表示します（作品が存在しないと断定はしません）。また Pixiv のタイトルは同人誌のタイトルと異なることが多く、別名で存在する作品を拾えない場合があります。

## 変更履歴

**0.3.1**

* ストア検索キーワードから句読点と「出典注記」を除去しました。
  * 実測（2026-09）: キーワードに句読点が含まれる場合（例 `サンプル！作品 第2巻`）、Melonbooks は **0 件**を返し、空白区切りの形なら商品が見つかります。つまり句読点は検索を黙って失敗させます。ストアへ送るキーワードは句読点を空白に置き換えます。画面に出すタイトルは元のまま、スコアにも影響しません（マッチャーは元々句読点を無視します）。
  * 末尾の「出典・仕様」括弧（雑誌号 `(サンプルマガジン Vol.54)`、ページ数 `(…ページ)`、イベント号 `(C…)`）を、巻数の除去より**前に**外すようにしました。先に `Vol.54` を消すと `(名称 )` という空殻が残り、キーワードが何もヒットしなくなっていました。
  * 報告いただいたページで検証済み: 2件は Melonbooks で一致度 100 のヒット、3件目のストア検索リンクは掲載号に到達します（その1件は「見つかりません」のまま。既知の制限 11 参照）。

**0.3.0**

* 「新しいページを開いた直後に読み取らないことがある」問題を修正しました。ポップアップに**前のページ**の作品が表示されることがありました。当時はギャラリーサイトの**トップページのキャッチコピー**を作品名と誤認し、「該当する商品は見つかりません」と表示されていました。
  * 原因: これらのサイトは**クライアントサイド遷移**（URL だけ変わり、ページは再読み込みされず、content script も作り直されない）を行います。その途中は「URL は新しい作品、DOM は前のページ」という状態になります。
  * content script に**遷移ゲート**を追加: `pushState` / `popstate` / URL ポーリングのいずれかで変化を検出したら、DOM が実際に入れ替わるまで待ってから（400ms の静穏、最大 5 秒）読み取ります。
  * 遷移中はページ情報の要求に古い内容で答えず、新しい内容が揃うまで待ちます。前のページのカードもその場で取り除きます。
  * `settled` シグナルを追加: `og:url` / `canonical` がアドレスバーと食い違う場合は「切り替え中」として扱い、検索には使いません。
  * 状態にドキュメント識別子（`page.scriptId`）を持たせ、同じドキュメントのときだけキャッシュを再利用。バックグラウンドもタブが同じ URL に留まっている場合のみ状態を保存します。
* 実サイトで検証済み（[検証](#検証)）。テストは 141 件。

**0.2.2** — サイトのルート / 一覧ページを分析対象から除外。ナビゲーションの文言を「作品ページ」の根拠にしないようにしました。

**0.2.1** — 別ページに属するキャッシュ状態をポップアップが破棄。タブごとに進行中の解析を重複排除。

**0.2.0** — **FANZA** と **Melonbooks** のアダプタを追加（DLsite → FANZA → Melonbooks、高確度が出た時点で終了）。既存のブラウザ Cookie による FANZA の年齢確認、ストアごとの結論表示。

**0.1.x** — タイトル抽出と整形（日本語優先、翻訳タグや話数の除去）、ページ上のカード、ポップアップ、DLsite アダプタ、オフラインのスナップショットテスト。
